# Specialist dispatch lessons

Recurring difficulties and their countermeasures, across phases. `PROMPT`-tagged entries are pasted
**verbatim** into every dispatch they bind on — a paraphrased gate command becomes a narrower gate.

Source: backend review of Plan 1, 2026-08-28.

| # | Lesson | Tag | Binding on |
|---|---|---|---|
| L1 | `tests` is not importable under `pythonpath = ["src"]`. Create `tests/__init__.py` and one per subpackage in the scaffold; set `pythonpath = ["src", "."]`. The failure names a module that visibly exists on disk, which sends you looking in the wrong place. | PROMPT | T-1 |
| L2 | **The gate is one command, run whole.** A path-scoped `pytest tests/<dir>` passes where the gate fails. Never report a narrower run as green, and a run that stops at type-check is not green. | PROMPT | every task |
| L3 | `import-linter`'s `layers` order is a trap that reads as correct: listing `infrastructure` above `application` *permits* the inward violation it appears to forbid. Prove the contract by adding a violating import and watching `lint-imports` fail before trusting it. | PROMPT | T-1 |
| L4 | Use the `lint-imports` script, not `python -m importlinter.cli`, and keep the config in `pyproject.toml`, not `setup.cfg`. The module entry point is cwd-dependent and fails differently under pytest's rootdir. | PROMPT | T-1 |
| L5 | The two redirect stubs produce **seven V3 findings that are not bugs** — they cite their successor's reference paths as prose. Spec §4 exempts artifacts with `superseded_by` set. Expect this; do not debug the regex. | PROMPT | T-3, T-9 |
| L6 | `~/.claude/` is a *target* layout, not a library layout — it has no `library.yaml`, so tags, collections and supersession all read empty. A smoke test against it tells you far less than it appears to. Acceptance uses a fixture library committed to the repo. | PROMPT | T-5, T-9 |
| L7 | `hl mcp` dies silently on any stdout write, including Typer's own error output on a bad flag. The failure surfaces as a malformed JSON-RPC stream with no clue why. Write the stdout-purity test before the server. | PROMPT | T-8 |
| L8 | **`ruff format .` rewrites Python code fences inside Markdown**, and reports only "N files reformatted" with no filenames — so a specialist can silently edit documents outside their territory and neither party notices. `[tool.ruff] extend-exclude = ["docs"]` must survive every pyproject edit. **Before reporting done, confirm `git status --porcelain docs/` shows nothing but your own task plan.** | PROMPT | every task |
| L9 | **`uv` is not installed and `pip install --user uv` is refused (PEP 668).** Bootstrap: `pip download --no-deps uv`, unzip the wheel, copy `uv-*.data/scripts/uv` to `~/.local/bin/uv`. `~/.local/bin` is **not** on the agent shell's default PATH and env does not persist between bash calls, so **every** gate invocation needs `export PATH="$HOME/.local/bin:$PATH"` prefixed or it fails as "command not found". | PROMPT | every task |
| L10 | **An exit-code-only contract test is theatre**: deleting a contract from `pyproject.toml` also yields exit 0 from `lint-imports`. `tests/test_architecture.py` asserts each contract is reported `KEPT` **by name**, parametrized. **If you add a fourth contract, extend `CONTRACT_NAMES` in that file** or the new contract is unguarded. | PROMPT | any task adding a contract |
| L11 | The `mcp` package pulls `starlette`, `uvicorn` and `sse-starlette` transitively. They are present in the venv and **must not be used** — D8 fixes the transport as stdio, and an HTTP path reopens decisions the spec closed. | PROMPT | T-8 |
| L12 | **A mutation that preserves the property your test asserts is invisible to it.** Verified: reversing the sort inside the content hash leaves `hash(A) == hash(reversed(A))` passing, because a reversed sort is still deterministic and still order-independent. Only a pinned golden value caught it. **Whenever a mutation check changes an ordering or normalisation rule, the test needs a golden literal, not an equality between two computed values.** Do not "simplify away" a golden digest. | PROMPT | any task with an ordering or normalisation rule |
| L13 | **`import-linter` does not police the standard library.** `domain-is-pure` stays KEPT while a domain module imports `subprocess` — which is exactly where R5's `git log` call will want to live. `tests/domain/test_purity.py` is the second guard: it inspects what each domain module actually bound at import time, so an alias or re-export cannot evade it. Extend it, never weaken it. | PROMPT | T-5 especially |
| L14 | **A grep across `docs/` hits documents your READ SCOPE bars you from.** Scope greps with `--exclude` for the barred files, or the exclusion is unenforceable in practice. Barred here: `docs/specs/**`, `docs/plans/**`, `implementation-record.md`, and any `*-review.md` in your initiative folder. | PROMPT | every task |
