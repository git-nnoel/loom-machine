# Specialist dispatch lessons

Recurring difficulties and their countermeasures, across phases. `PROMPT`-tagged entries are pasted
**verbatim** into every dispatch they bind on — a paraphrased gate command becomes a narrower gate.

Source: backend review of Plan 1, 2026-08-28.

| # | Lesson | Tag | Binding on |
|---|---|---|---|
| L1 | `tests` is not importable under `pythonpath = ["src"]`. Create `tests/__init__.py` and one per subpackage in the scaffold; set `pythonpath = ["src", "."]`. The failure names a module that visibly exists on disk, which sends you looking in the wrong place. | PROMPT | T-1 |
| L2 | **The gate is one command, run whole.** A path-scoped `pytest tests/<dir>` passes where the gate fails. Never report a narrower run as green, and a run that stops at type-check is not green. | PROMPT | every task |
| L3 | `import-linter`'s `layers` order is a trap that reads as correct: listing `infrastructure` above `application` *permits* the inward violation it appears to forbid. Prove the contract by adding a violating import and watching `lint-imports` fail before trusting it. | PROMPT | T-1 |
| L4 | Use the `lint-imports` script, not `python -m importlinter.cli`, and keep the config in `pyproject.toml`, not `setup.cfg`. The module entry point is cwd-dependent and fails differently under pytest's rootdir. | PROMPT | T-1 |
| L5 | The two redirect stubs produce **seven V3 findings that are not bugs** — they cite their successor's reference paths as prose. Spec §4 exempts artifacts with `superseded_by` set. Expect this; do not debug the regex. | PROMPT | T-3, T-9 |
| L6 | `~/.claude/` is a *target* layout, not a library layout — it has no `library.yaml`, so tags, collections and supersession all read empty. A smoke test against it tells you far less than it appears to. Acceptance uses a fixture library committed to the repo. | PROMPT | T-5, T-9 |
| L7 | `hl mcp` dies silently on any stdout write, including Typer's own error output on a bad flag. The failure surfaces as a malformed JSON-RPC stream with no clue why. Write the stdout-purity test before the server. | PROMPT | T-8 |
| L8 | **`ruff format .` rewrites Python code fences inside Markdown**, and reports only "N files reformatted" with no filenames — so a specialist can silently edit documents outside their territory and neither party notices. `[tool.ruff] extend-exclude = ["docs"]` must survive every pyproject edit. **Before reporting done, confirm `git status --porcelain docs/` shows nothing but your own task plan.** | PROMPT | every task |
| L9 | **`uv` is not installed and `pip install --user uv` is refused (PEP 668).** Bootstrap: `pip download --no-deps uv`, unzip the wheel, copy `uv-*.data/scripts/uv` to `~/.local/bin/uv`. `~/.local/bin` is **not** on the agent shell's default PATH and env does not persist between bash calls, so **every** gate invocation needs `export PATH="$HOME/.local/bin:$PATH"` prefixed or it fails as "command not found". | PROMPT | every task |
| L10 | **An exit-code-only contract test is theatre**: deleting a contract from `pyproject.toml` also yields exit 0 from `lint-imports`. `tests/test_architecture.py` asserts each contract is reported `KEPT` **by name**, parametrized. **If you add a fourth contract, extend `CONTRACT_NAMES` in that file** or the new contract is unguarded. | PROMPT | any task adding a contract |
| L11 | The `mcp` package pulls `starlette`, `uvicorn` and `sse-starlette` transitively. They are present in the venv and **must not be used** — D8 fixes the transport as stdio, and an HTTP path reopens decisions the spec closed. | PROMPT | T-8 |
| L12 | **A mutation that preserves the property your test asserts is invisible to it.** Verified: reversing the sort inside the content hash leaves `hash(A) == hash(reversed(A))` passing, because a reversed sort is still deterministic and still order-independent. Only a pinned golden value caught it. **Whenever a mutation check changes an ordering or normalisation rule, the test needs a golden literal, not an equality between two computed values.** Do not "simplify away" a golden digest. | PROMPT | any task with an ordering or normalisation rule |
| L13 | **`import-linter` does not police the standard library.** `domain-is-pure` stays KEPT while a domain module imports `subprocess` — which is exactly where R5's `git log` call will want to live. `tests/domain/test_purity.py` is the second guard: it inspects what each domain module actually bound at import time, so an alias or re-export cannot evade it. Extend it, never weaken it. | PROMPT | T-5 especially |
| L15 | **Bash inside a worktree-isolated agent refuses compound commands.** A `for` loop, a `cd X && …`, and a `python3 - <<'EOF'` heredoc are all rejected as unverifiable, with no override. Flat `a && b && c` with absolute paths is fine. **For anything with a loop, heredoc or `cd`, write a `.py` to the scratchpad and run `python3 /abs/path.py`.** cwd also resets between calls, so every path must be absolute. Cost the first agent three wasted round trips. | PROMPT | any worktree-isolated task |
| L16 | **`ruff` E501 applies to docstring and comment prose, and `ruff format` will not fix it.** `ruff format .` reports "all formatted", then `ruff check` produces dozens of E501s over prose the formatter declined to rewrap. This project's docstrings are long by convention. Wrap prose at ~99 columns while writing. **Do not bulk-reflow with a script** — one attempt merged `#` comment lines into the following statements and destroyed banner rules, producing syntax errors across four files. Also: `RUF001`/`RUF002` reject an en dash in a string literal, so write `V1-V7` with a hyphen in code. | PROMPT | every task |
| L17 | **PyYAML ships no type hints and `types-PyYAML` is deliberately absent from the dev group.** `import yaml` fails the gate at `mypy` with "Library stubs not installed", which looks like a missing package and invites a dependency change — the exact boundary you may not cross. The project's answer is one `# type: ignore[import-untyped]` in the single quarantine module `infrastructure/_yaml_document.py`, which hands out a typed node model so `Any` does not spray through the layer. **If a second module needs PyYAML, stop and ask** rather than adding a second ignore. | PROMPT | any task touching YAML |
| L18 | **Moving a module into `domain/` costs two edits, not one.** `tests/domain/test_purity.py::EXPECTED_MODULES` must list it (L13), **and** whatever stdlib it binds must be legal there. `import-linter` reports all three contracts KEPT with a `pathlib` import sitting in `domain/` — only the purity test catches it. Check what a module imports before assuming an inward move is a one-line change. The repair is to narrow the module, never to relax the guard. | PROMPT | any task moving a module inward |
| L19 | **L16's reflow trap bites at single-edit scale too.** A multi-line `str.replace` whose old text ends mid-paragraph re-joins the remainder onto one line; `ruff format` will not rewrap prose, and E501 then fires on a line you did not think you touched. Cost one agent three gate attempts. **Edit docstring prose one physical line at a time, and run `uv run ruff check .` immediately after any prose edit** rather than discovering it at the end of a full gate run. | PROMPT | every task |
| L20 | **`I001` fires on `from tests.… import …`.** `pyproject.toml` sets `src = ["src", "tests"]`, so ruff treats `tests` as first-party and wants it in the same import block as `harness_library`, with no blank line between. `ruff check --fix` resolves it. Only bites tasks whose tests import a shared fake or fixture helper. | PROMPT | any task importing from `tests.` |
| L21 | **`ruff` exits 2 on a broken symlink anywhere in the tree**, before any rule runs and with no rule code: `error: Failed to read …: No such file or directory`. A committed symlink fixture must point at a **real** file. The fixture library's link is deliberate and points outside its artifact root — do not "repair" it. | PROMPT | any task touching `tests/fixtures/` |
| L22 | **The fixture library flips state at the commit boundary.** It lives inside this repo, so it is untracked-and-dirty to the specialist who creates it and committed-and-clean to everyone after. Any R5 timestamp assertion against it passes for its author and fails for the next agent. Assert timezone-awareness against the fixture; prove R5 itself in a `tmp_path` repository. | PROMPT | T-9 and any task asserting timestamps |
| L23 | **`UnicodeDecodeError` is a subclass of `ValueError`.** The obvious handler order silently reports every binary file as a malformed path — wrong code, wrong HTTP status, diagnosis aimed at the request instead of the file. No type checker catches a reorder. `application/read/_access.py` catches `UnicodeDecodeError` **first** and three tests guard it. Anyone touching error translation in initiative 02 or 03 will meet this again. | PROMPT | any task translating errors |
| L24 | **Adding a member to a Protocol is a multi-file edit.** `mypy --strict` fails in every directory holding a hand-written fake, including ones your scope does not name. Grep for classes asserted against the protocol before estimating the change. | PROMPT | any task touching a protocol |
| L25 | **The record can be ahead of the code on a frozen contract.** A ruling that amends a contract lands in the documents; the protocol file only changes when someone is dispatched to change it. "Stop and report" is right when no ruling exists — but grep the record's ruling table for the missing member first, because when a ruling already covers it, transcribing is not amending and stopping costs a full round trip. | PROMPT | every task |
| L14 | **A grep across `docs/` hits documents your READ SCOPE bars you from.** Scope greps with `--exclude` for the barred files, or the exclusion is unenforceable in practice. Barred here: `docs/specs/**`, `docs/plans/**`, `implementation-record.md`, and any `*-review.md` in your initiative folder. | PROMPT | every task |
